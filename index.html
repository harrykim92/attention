GPT는 다음 토큰을
어떻게 고를까?

Q는 지금 막 처리 중인 마지막 위치에서 만들고, 과거 토큰의 K/V는 KV Cache에 저장해 다시 계산하지 않습니다. 아래에서 한 토큰씩 직접 진행해 보세요.

Q = 지금 묻는 질문현재 토큰의 hidden state를 Q로 projection
K = 찾아보기 위한 표지각 과거 토큰이 “나는 이런 정보야”라고 붙인 키
V = 실제 가져올 내용Q와 K의 유사도로 가중합되는 정보

3. KV Cache

과거 토큰의 K/V는 저장됩니다. 이전 Q는 다시 쓰지 않으므로 저장할 필요가 없습니다.
K Cache
V Cache
왜 Q Cache는 없을까?
token 1의 Q는 token 1을 처리할 때만 필요합니다. 다음 step에서는 새로운 마지막 token에서 새로운 Q를 만들면 됩니다. 반대로 K/V는 미래의 모든 token이 계속 참고해야 하므로 cache합니다.
정확히는 첫 번째 생성 token에서 조금 다릅니다
Prefill 단계에서 prompt 전체를 한 번에 계산합니다. 이때 prompt의 모든 K/V가 cache되고, 마지막 prompt 위치의 출력으로 바로 첫 generated token을 예측할 수 있습니다. 그 다음부터는 새로 생성된 token 하나만 입력해 Q/K/V를 만들고, K/V를 cache에 하나씩 추가합니다.
Attention(Q,K,V) = softmax(QKᵀ / √d) · V

Decode 반복

방금 생성한 token 하나만 새로 계산합니다. 새 K/V는 cache에 추가하고, 새 Q로 다음 token을 또 예측합니다.
